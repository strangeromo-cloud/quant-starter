# 短线动量（Martin Luk 式）日线回测研究

> 脚本：`bt_swing.py`（`pull` 建池拉数 / `run` 跑全部变体 / `report` 生成本文表格）
> 回测区间：2012-01-03 ~ 2026-10-16，美股随机 300 只，日线，扣单边 0.1% 成本
> 结论：**no_edge（没有优势）**。v1 规则在日线近似下每笔期望为 **-0.31R**（95% 置信区间 -0.49 ~ -0.14），
> 两段样本外都是负数，远不如同一股票池等权买入持有。

## 0. 一句话结论（可直接放进卡片）

`日线回测2012-26：年化-5.5%/回撤-60%/期望-0.31R，远不及同池等权+16.7%，无优势`

给负责人的建议见第 6 节。简单说：**只当观察雷达，不按它下单，也不按 R 仓位上真钱**。

## 1. 要回答的问题

视频里的打法（Martin Luk，2025 USIC 股票组冠军 +969.8%，胜率约 22%，赢一笔平均 14%、亏一笔平均 2%）
完全靠"亏小赚大"。这种打法很容易被幸存者偏差和挑出来的几张漂亮图骗。这里想诚实地回答：

1. 把它翻译成**只用日线、无未来函数**的固定规则（规范日线规则 v1，与生产纸面跟踪同一套），
   在一个**随机**美股池上，扣掉成本以后，每笔交易的期望 R 是不是正的？
2. 组合层面的风险调整收益，能不能明显好过**同一股票池等权买入持有**和 QQQ？
3. 两段样本（2012-2018 / 2019-至今）是否都成立？换参数、加市场过滤后结论会不会翻？

## 2. 方法

### 2.1 规范日线规则 v1（参数是 `bt_swing.py` 顶部 `Params`，与 `config.SWING` 对齐）

| 环节 | 规则 |
|---|---|
| 资格（t 日收盘） | 价格 ≥ 5$；20 日均成交额 ≥ 5000 万$；ADR20 = mean(high/low-1) ≥ 3.5%；close > EMA21 |
| 趋势叠层 | EMA9 > EMA21 > EMA50，且 EMA21 > 5 个交易日前的 EMA21 |
| 观察名单 | 资格池里当日涨幅前 20 且涨幅 ≥ 3% 进入；保留 20 个交易日；收盘跌破 EMA50 提前移出 |
| 回调 | 趋势叠层；low ≤ EMA9×1.005 且 close ≥ EMA21；close/EMA50-1 ≤ 25%；触发 = 当日高，止损 = 当日低 |
| 突破 | 趋势叠层；inside day 或振幅 ≤ 0.6×ADR20×close；\|close/EMA9-1\| ≤ 3%；近 10 日振幅 ≤ 3×ADR20 |
| EP | open ≥ 昨收×1.10 且 量 ≥ 3×前 50 日均量（扫资格池，不要求事先在观察名单里） |
| 止损过滤 | (触发-止损)/触发 ≤ min(ADR20/2, 3%) |
| 执行（t+1） | 开盘 > 触发 → 按开盘成交（若 (开-止损)/开 > 4.5% 放弃）；否则最高 ≥ 触发 → 按触发价成交 |
| 同 K 线 | 成交后当日最低 ≤ 止损 → 判止损（保守，另做折中/乐观对照） |
| 仓位 | 风险 = 0.5%×当前权益；股数 = 风险/(成交价-止损)；单仓 ≤ 25%；总敞口 ≤ 100%（现金账户）；同股只持一笔 |
| 管理 | 满 3 个交易日且 EMA9 > 成本 → 止损上移到成本；close ≥ EMA9×1.20 → 卖 15%（一次）；close < EMA9 → 收盘全卖；盘中 ≤ 止损 → 按止损出（开盘就低于止损按开盘价出） |

几处 BRIEF 没写死、这里的取舍：

- 观察名单在 t 日先更新再判形态（当天新进名单的股票当天就可以出形态）；回调/突破只要求当天流动性合格
  （价 ≥ 5$、成交额 ≥ 5000 万$），不再要求 ADR ≥ 3.5%：突破形态的收窄本身就会压低 ADR20。
- 同一只股票同一天满足多个形态时按 EP > 突破 > 回调 记一个标签。
- 跟踪均线 v1 从成交当天就生效（"收盘跌破就走"），另做"挪到保本后才生效"的变体（`trail_be`），
  这更接近视频里"剩下的仓位用 9EMA 跟踪"的原意。
- 股数允许小数（1 万美元账户买 3000$ 的股票时，整数股会让仓位失真），结论与账户规模无关。

### 2.2 组合层面逐日模拟

每个交易日依次处理：① 持仓先看跳空低开 / 盘中止损，再看收盘规则；② 撮合前一晚的挂单；③ 收盘盯市；
④ 收盘出新挂单（受市场过滤 / 熔断约束）。仓位按**前一日收盘权益**计算；现金不足或总敞口满了就不再开新仓。

挂单排队优先级 quality（0~1，高者先成交，三项线性加权）：

- 0.5 × 相对强度：63 日涨幅在当日流动性合格池里的百分位（"同板块挑最强"的日线近似）
- 0.3 × 止损紧度：1 - 止损距离 / 允许上限（越紧，同样风险买得越多，R 倍数也越大）
- 0.2 × 趋势斜率：clip((EMA9/EMA50-1)/20%, 0, 1)

实际敞口很低（平均 12%），排队优先级几乎不起作用，结论对它不敏感。

1R = 成交时的股数 × (成交价 - 止损)；每笔的 R = 这笔所有卖出的净盈亏（含两侧成本）/ 1R。

### 2.3 对照组

- SPY、QQQ 买入持有（拆股复权价，另给含分红的全收益版本）。
- **同一股票池等权买入持有，月末再平衡**：只纳入再平衡日已有收盘价的股票，扣再平衡换手成本。
  股票池是"今天的大中盘股"，本身带幸存者偏差；等权持有吃的是同一份偏差，所以它是最公平的比较对象。

### 2.4 变体与稳健性

市场过滤 F0/F1/F2（另加一个用流动池算宽度的 F2'）；止损上限 3% vs 5%；每笔风险 0.5% vs 1%；
跟踪 EMA9 vs EMA21；跟踪是否等保本后才启用；有/无连亏熔断；三种形态分开跑；成本 0 / 0.1% / 0.2%；
同 K 线保守 / 折中 / 乐观；观察名单按池子规模收紧到前 3 名；**安慰剂对照**（5 个种子）；
**入场漂移诊断**；**子池自助抽样**（300 只里随机抽 150 只，重复 30 次）。

市场过滤的口径（都在 t 日收盘判定，决定 t+1 能否开新仓）：

- F1：QQQ close > EMA21 且 EMA9 > EMA21 且 EMA21 > 5 日前 → 2012 年以来 60% 的交易日允许开仓。
- F2：资格池里强档（close > EMA50 > EMA150）占比 ≥ 40%。资格池不足 5 只的日子（占 36%）记为缺失、不开仓；
  有效日里强档占比平均 55%，74% 的有效日达标。资格池本身要求 close > EMA21，所以这个口径天然偏高、区分度差。
- F2'：同样的强档定义，但分母换成流动池（价 ≥ 5$ 且 20 日均成交额 ≥ 5000 万$，不看 ADR 和 EMA21），
  平均 44%，63% 的日子达标。这更接近"观察名单宽度"的原意。

## 3. 数据与偏差

### 3.1 股票池

- BRIEF 指定用东财行情榜建池。实际建池时东财 `push2` 各节点连续返回 502 / 断开连接（同一出口 IP
  上还有别的任务在探测，判断是被限流），**退到 Nasdaq 官网 screener**（一次请求覆盖全部美股，
  有价格、成交量、总市值）。过滤条件不变：市值 ≥ 10 亿$、最近一个交易日（2026-10-16）成交额
  （价 × 量）≥ 2000 万$；剔除名称含 ETF/Fund/Trust/iShares/SPDR/ProShares/Direxion/Invesco、
  优先股、权证、Units、Rights、票据等的标的。来源记在 `universe.csv` 的 `source` 列。
- 合格普通股 1984 只，用种子 42 随机打乱后取前 300 只（IOND 只有 58 根 K 线，由下一个备选顺补）。
  市值中位数 76 亿$，42% 在 100 亿$ 以上；行业分布：科技 58、可选消费 57、金融 52、医疗 39、工业 38。
- 清单：`swing_cache/universe.csv`（`status` 列：selected / reserve / fail）。

### 3.2 行情

- Twelve Data 日线 `outputsize=5000`（2006-11 起），含 OHLCV。共调用 **308 次**
  （NVDA 核对 1 + 基准 6 + 个股 301），每次间隔 9 秒，全程没遇到 429。拉完写了 `_PULL_DONE`。
- **拆股复权核对**：NVDA 2024-06-10（10:1）前一日收盘 120.89 / 当日 121.79，2021-07-20（4:1）
  前后 18.78 / 18.61，成交量也已按拆股放大 → Twelve Data 已拆股复权，不需要自己修。
  （`fix_unadjusted_splits()` 留着做兜底，但没有启用：它会把真实的单日腰斩误判成拆股。）
- 价格不含分红。策略平均只持有 2.8 天，分红影响可忽略；同池等权和 SPY/QQQ 主比较用的也是不含分红的
  价格，口径一致（SPY 含分红每年约多 1.9 个百分点，见对照表）。
- 清洗：非正价格剔除；high/low 包住 open/close；单日 ×3 又回落到 0.4 以下的孤立尖刺剔除。

### 3.3 已知偏差（方向）

| 偏差 | 对策略结果的影响 |
|---|---|
| 幸存者偏差：池子是"今天还活着、市值 ≥ 10 亿$"的公司，历史上退市/缩水的不在里面 | **偏乐观**。动量策略最受益（能骑上后来的大赢家，比如 GEV 一笔 +34R）。等权对照吃同一份偏差 |
| 市值 ≥ 10 亿$ 只在建池时（今天）检查，历史上用 20 日均成交额 ≥ 5000 万$ 近似 | 中性偏乐观 |

| 现金收益按 0 计 | 偏悲观。平均敞口只有 12%，按 2012-2026 平均约 2% 的现金利率算，每年少算约 1.7 个百分点，改变不了结论 |

| 小数股、无借券/无做空 | 中性 |

### 4.6 诊断

**A. 入场本身有没有方向性？**（不管止损和卖出，只看按 v1 撮合能成交的信号，成交价到之后第 k 日收盘）

| 信号 | 成交笔数 | 当日最低触及止损 | 当日收盘 | 1 日 | 5 日 | 10 日 | 20 日 |
|---|---|---|---|---|---|---|---|
| v1 形态 | 829 | 39% | -0.00% | -0.07% | -0.13% | -0.16% | +0.47% |
| 安慰剂 #0 | 776 | 40% | -0.06% | -0.07% | +0.06% | -0.02% | +0.57% |
| 资格池任意股票日（无条件） | — | — | — | +0.03% | +0.25% | +0.64% | +1.38% |

在日线上"买过前一日高点"之后，平均来说**没有任何延续**，10 日以内甚至跑输资格池里随便一只股票。
入场没有方向性，止损和仓位管理就只能把约等于 0 的漂移，变成扣掉成本、再加上跳空止损之后的负期望。

**B. 形态有没有增量信息？** 安慰剂对照：每天用同样数量、从"流动 + 资格 + 趋势叠层 + 止损够窄"的股票里
随机抽，触发价和止损同样取当日高点和低点。5 个种子的期望 R 在 -0.21 ~ -0.31，v1 是 -0.31。
**回调 / 突破这几条形态条件没有增量信息**：v1 和"随便挑一只窄幅日的趋势股"没有差别。

**C. 换一批股票会不会翻？** 子池自助抽样，从 300 只里随机抽 150 只，重复 30 次：

| 方案 | 期望R 均值 | 最小 ~ 最大 | 期望R > 0 的比例 | Sharpe 均值 / 最大 | 跑赢同子池等权 Sharpe |
|---|---|---|---|---|---|
| base | -0.31 | -0.49 ~ -0.03 | 0/30 | -0.48 / 0.04 | 0/30 |
| F2' | -0.25 | -0.51 ~ +0.21 | 1/30 | -0.31 / 0.34 | 0/30 |

（同子池等权的 Sharpe 平均 0.89。）

**D. 为什么"亏小赚大"在这里不成立？** 胜率 16.3%、平均亏 0.99R 时，要打平，平均每笔赢的必须有
(1-0.163)/0.163 × 0.99 ≈ **5.1R**，实际只有 3.2R。视频里 2025 年是胜率约 22%、赢 7R 左右
（14%/2%），期望约 +0.8R。差距来自两个地方：

1. **止损太早被扫**：39% 的单子成交当天最低价就碰到止损。日线上止损只能放在前一日低点，
   而前一日之所以入选，恰恰是因为它振幅窄（≤ 0.6×ADR）；第二天正常波动一个 ADR，就会同时扫过前高和前低。
   视频里的止损放在 1 分钟图上刚砸出来的低点，是另一回事。
2. **赢的单子拿不住**：赢单平均持有 10 天，收盘一破 EMA9 就走；从未触发过"高出 EMA9 20% 卖 15%"
   （681 笔里只有 1 笔）。换成 EMA21 跟踪后平均赢到 5.3R，但胜率掉到 10.6%，期望没有改善。
3. 结果高度依赖少数大单：最好的 5%（34 笔）合计 +245R，其余 647 笔合计 -458R。

**E. 保守处理同 K 线低估了多少？** 只有"盘中触发成交"的单子才有歧义（开盘成交的单子，最低价一定在成交之后）。

| 同 K 线假设 | 期望R | 年化 | 回撤 |
|---|---|---|---|
| 保守（v1）：成交后当日最低 ≤ 止损就判出局 | -0.31 | -5.5% | -59.5% |
| 折中：阳线按 O→L→H→C、阴线按 O→H→L→C | -0.16 | -2.4% | -38.1% |
| 乐观：一律假设低点在成交之前，只看收盘 | -0.15 | -2.4% | -38.8% |

保守处理大约低估 **0.15R/笔**，相当于每年约 3 个百分点。但即使全部按乐观算，期望仍是负的，
置信区间上沿只到 +0.03R。

## 5. 结论

**verdict = no_edge。**

- 扣成本后，所有 20 多个变体每笔的期望都是负的；连零成本、乐观同 K 线也是负的。
- 风险调整收益全面落后：最好的规则变体（F2'）Sharpe 是 -0.38（把同 K 线歧义全按乐观算也只有 -0.23），同池等权是 0.91，QQQ 是 0.94。
- 两段样本外都不成立，而且 2019 年以后更差；2025 年（视频冠军年）是最差的一年。
- 安慰剂对照说明，回调 / 突破的形态条件在日线上没有信息；入场漂移诊断说明，在日线上买过前高本身就没有延续。
- 偏差的方向对策略有利（幸存者偏差：池子里全是活下来、长大了的公司），在这种情况下仍然是负的，真实结果只会更差。

需要强调的边界：这个结论只覆盖**日线可以表达的部分**。Martin 的优势（如果确实存在）大概率在盘中执行：
开盘假突破之后在 1 分钟图上接回，止损放在刚砸出来的低点，止损距离和胜率都和日线近似完全不同。
另外，一个人一年 940 笔、胜率 22% 的冠军成绩，本身也是从大量参赛者里挑出来的尾部结果。
这两点用日线数据既证明不了，也证伪不了。

## 6. 给负责人的建议

1. **只做观察雷达**：卡片上照常列出资格池 / 观察名单 / 当日形态（选股 + 看盘的提示有用），
   但不发"买入"指令，不给 R 仓位建议，卡片底部固定挂上这条回测结论。
2. **不要上真钱，也不要提高风险**：每笔风险 1% 只会让回撤更大（-60%）；连亏熔断能降敞口、
   把回撤压到 -48% ~ -53%，但不改变期望的符号。
3. 生产默认参数**保持 v1 不变**（纸面跟踪必须和回测同一套，才能互相印证）。如果卡片要一个市场环境开关，
   用"流动池宽度 ≥ 40%"（F2'）比 QQQ 趋势（F1）更有信息量（回撤 -39% vs -53%），但它同样只是"少亏"，
   不是优势，不能作为"可以出手"的依据。
4. 纸面跟踪积累到 **≥ 100 笔、期望 R 的 95% 置信区间下沿 > 0** 之前，不讨论实盘。
   按回测预期，纸面结果大概率是负的；如果纸面明显好于回测，先排查是不是纸面成交价记录得太乐观。
5. 如果还想继续研究，唯一值得测的方向是**盘中执行**（开盘区间回踩 / 1 分钟突破前一根高点、止损放在分钟级低点）。
   这需要分钟数据，Twelve Data 免费版的额度和历史长度都不够，要单独评估数据成本。

## 7. 复现

```bash
export TWELVEDATA_KEY=...            # 只有 pull 需要 key
python bt_swing.py pull     # 建池 + 拉数（断点续传，已缓存不重复拉），完成后写 _PULL_DONE
python bt_swing.py run      # 全部变体 + 对照 + 诊断，写 _results.json 和 _trades_base.csv（约 25 秒）
python bt_swing.py report   # 把 _results.json 渲染成本文的 Markdown 表
```

缓存目录默认是仓库内 `output/swing_cache`（已 gitignore，研究用的 300 只日线已放在这里，可直接重跑），可用环境变量 `SWING_CACHE` 覆盖。
`run` / `report` 只读本地缓存，不连数据库、不调任何外部接口、不发 Lark。
